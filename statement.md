# Project Statement: Mobile Phone Usage Trends Explorer

## Problem statement

It is challenging to grasp how mobile phone usage has changed throughout time. The project provides the mobile-user data in the form of easily understandable charts and summaries that users can interact with to become more aware of the trends in mobile-phone usage.

## Project scope

The project is a menu-driven Python application that reads the mobile phone user-count data from a CSV file. It focuses on examining the trends of the mobile-phone user counts by the country and city over years. The application allows users to view charts, see summary statistics, sort and filter the records, calculate growth rates, delete duplicates, and save the modified records as CSV files.

The current application provides only a local command line interface and a visualisation using the Matplotlib library. It does not provide a website, mobile application, live data feed, or prediction tools.

## Target users

The application may be used by members of the general public interested in mobile phone usage trends. Students and educators may be able to use the data set for teaching or learning. The application may attract the users interested in comparing mobile phone user counts in different cities, countries, or years.

## High-level features

• Examine the mobile phone user counts for a specific country and city.

• Visualise the city-level trends in mobile phone usage with line and bar charts.

• Compare the records of up to five cities of choice on a line chart.

• See an overview of all records, the ones with the highest counts, and statistical summary.

• Sort and filter the records by country or year.

• Calculate growth rates, remove duplicates, and sort records.

• Save the modified records as CSV files.
